# まぼろしフォト（maboroshi-photo） v1.1.0

AIのミッションが来たときだけ撮影でき、写真はミッション終了と同時にいっせいに地図へ現れ、決められた時間で消える位置連動フォトシェアWebアプリ。

## ディレクトリ構成

```
maboroshi-photo/
├─ index.html          画面（認証・地図・各シート）
├─ css/style.css       デザイン
├─ js/config.js        設定（GAS URL・初期値・演出動画パス）
├─ js/api.js           GAS通信・ログイン状態の保持
├─ js/voice.js         音声入力（間を許容）・読み上げ（メタ発言除去）
├─ js/app.js           アプリ本体
├─ assets/earth/       Google Earth Studioの書き出し動画（auth.mp4 / mission.mp4）
├─ gas/Code.gs         GASバックエンド（GitHub Pagesには不要、管理用）
└─ README.md
```

## しくみ

| 項目 | 内容 |
|---|---|
| ミッション | `MISSION_INTERVAL_MIN`（既定30分）ごとに抽選。出る場合は枠内のランダムな時刻に発令し、事前には知らせない。お題・読み上げ文・表示分数はGeminiが決める |
| 撮影 | 発令から `MISSION_WINDOW_MIN`（既定5分）だけ可能。1ミッション1枚 |
| 公開と消滅 | 撮影時間が終わった瞬間に全員の写真が同時に出現 → AIが決めた10〜60分で消滅。5分ごとのトリガーでDriveの写真をゴミ箱へ移し、コメント・いいねも削除 |
| 気配メーター | 待ち時間に「しずか→そわそわ→ざわざわ→どきどき→もうすぐ!?」の5段階で気配を表示。サーバーは正確な時刻を明かさず、ゆらぎのある数値と「6〜14分後かも」のような幅つき予報だけを返す（近づくほど幅が狭まる）。「どきどき」以上に上がると通知・振動・読み上げ |
| 予想ゲーム | メーターをタップして「5分以内／15分以内／30分以内／もっと先」を予想。発令時に答え合わせし、的中数・連続的中・最高連続を記録（端末に保存）。「もうすぐ!?」の間は締め切り |
| 表示条件 | いま公開中／少し前の足あと（30分〜24時間）× すべて／近く（○m以内）／遠く（○m以上） |
| プライバシー | 他人に見せる写真位置・現在地・足あとは約100mに丸める。本人には正確な位置で表示 |
| 安全 | コメントはNGワード＋Geminiで判定。通報するとその人には即非表示、3件で全員から非表示。ブロックは双方向で非表示 |

## セットアップ手順

### 1. GAS
1. 新しいGoogleスプレッドシートを作り、「拡張機能」→「Apps Script」を開く
2. `gas/Code.gs` の中身を貼り付けて保存
3. 関数 `setup` を選んで実行 → 権限を許可（シート・Driveフォルダ・PEPPERが自動作成されます）
4. 「プロジェクトの設定」→「スクリプト プロパティ」に追加
   - `GEMINI_API_KEY`：Gemini APIキー（必須）
   - `APP_URL`：`https://kenken6291.github.io/maboroshi-photo/`
   - 必要に応じて `GEMINI_MODEL`、`GEMINI_TTS_MODEL`、`TTS_VOICE`、`MISSION_*` など（Code.gs冒頭に一覧）
5. 関数 `testGemini` → `testMission` を実行し、ログに結果が出ることを確認（モデル名が違うとここでエラーになります）
6. 関数 `installTriggers` を実行（5分ごとの `cleanup` が登録されます）
7. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行ユーザー：自分
   - アクセスできるユーザー：全員
8. 表示されたウェブアプリURLをコピー

> コードを変更したときは「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」で再デプロイしてください。保存だけでは反映されません。

### 2. フロントエンド
1. `js/config.js` の `GAS_URL` を手順1-8のURLに置き換え
2. GitHubにリポジトリ `maboroshi-photo` を作成し、`gas/` 以外を push（`gas/` を入れても動作に影響はありません）
3. Settings → Pages → Branch を `main` / `root` にして公開
4. HTTPSで開くこと（カメラ・位置情報・マイクはHTTPSでのみ動きます。GitHub PagesはHTTPS）

### 3. Google Earth Studio の演出動画（任意）
1. Earth Studioでプロジェクトを作成（例：ログイン画面用に日本列島をゆっくり周回、ミッション用に上空から街へ急降下）
2. 720p・10〜15秒程度でレンダリング（連番画像で書き出されます）
3. 連番画像をmp4に変換（例）
   `ffmpeg -framerate 30 -i frame_%03d.jpeg -c:v libx264 -pix_fmt yuv420p -crf 28 -an auth.mp4`
4. `assets/earth/auth.mp4`、`assets/earth/mission.mp4` に置く（それぞれ5MB以下が目安）
5. 動画がない場合は自動的に非表示になります。ミッション動画の再生時は「映像：Google Earth」の表記が出ます（Earth Studioの利用条件で帰属表示が必要です）

### 4. 管理者
スプレッドシート `Users` シートの自分の行の `role` を `admin` に変更し、ログインし直すと、メニューに「いますぐミッションを出す」が表示されます。動作確認に便利です。

## 動作確認チェックリスト
- [ ] 新規登録：5項目すべてにチェックするまで登録ボタンが押せない
- [ ] 仮パスワードのメールが届く → ログインで強制パスワード変更が出る
- [ ] パスワード再発行メールが届く／5回失敗で15分ロック
- [ ] 目のアイコンでパスワード表示が切り替わる
- [ ] 管理者メニューからミッション発令 → 赤い表示・発令画面・読み上げ
- [ ] 撮影 → 投稿 → 自分には灰色のピン → 撮影時間終了で全員に出現 → 輪が減って消える
- [ ] 近く／遠く／足あとの切り替え
- [ ] コメントの投稿・編集・削除、いいね、通報、ブロックと解除
- [ ] 音声入力で言葉の間をあけても途切れない

## 注意
- ログインの有効期間は最終操作から6時間（GASのキャッシュの上限）です。
- Google Workspaceのアカウントで運用し、「リンクを知っている全員」への共有が組織で禁止されている場合は写真が表示されません。個人のGoogleアカウントでの運用をおすすめします。
- ゴミ箱に移した写真はDriveが30日後に完全削除します。
- 音声入力はブラウザの機能を使うため、Firefoxでは使えません。
